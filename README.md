# [Spatial proteogenomics of tumour-draining lymph nodes]

## Description
Code for the analysis in our manuscript 'Spatial proteogenomics of tumour-draining lymph nodes reveals the myeloid phospholipase PLA2G2D as a targetable regulator of anti-tumour immunity', first submitted to Nature in November 2025.
